Connect claude.ai directly (remote MCP)

Settings → Connectors → Add custom connector. Paste this as the Remote MCP server URL — no token to copy, claude.ai signs in as you through a login + authorize screen (OAuth).

Name it whatever you like. When you click Add, a browser tab opens asking you to log into CodeVault (if needed) and approve access — that's this instance's own login, not a third party.

Connect Claude Code / Claude Desktop (local MCP)

Uses the same API through a small local server instead — see mcp-server/README.md in the repo for setup. It authenticates with your API token directly (below) via CODEVAULT_BASE_URL / CODEVAULT_API_TOKEN, no browser login step needed.

Endpoints

GET/api/v1/projects/List your projects
POST/api/v1/projects/Create a project (or return the existing one with that name)
GET/api/v1/projects/<slug>/items/List items in a project
POST/api/v1/projects/<slug>/items/Push (create or update) an item
GET/api/v1/items/<uid>/Fetch one item's full code + metadata
POST/mcp/MCP endpoint — accepts either an OAuth access token (claude.ai's connector) or your API token as a Bearer header (Claude Code / Desktop / curl)

Push matches an existing item by uid > identifier > (kind + title), in that order — pushing the same script twice updates it instead of duplicating it. Screenshots (kind=image) aren't supported through the API.

Example: pull a project's items

curl {{ base_url }}/api/v1/projects/YOUR-PROJECT-SLUG/items/ \
  -H "Authorization: Bearer {{ token.key }}"

Example: push a Script Include

curl {{ base_url }}/api/v1/projects/YOUR-PROJECT-SLUG/items/ \
  -H "Authorization: Bearer {{ token.key }}" \
  -H "Content-Type: application/json" \
  -d '{
        "kind": "code",
        "script_type": "script_include",
        "title": "CalcUtils",
        "identifier": "CalcUtils",
        "language": "javascript",
        "content": "var CalcUtils = Class.create();\nCalcUtils.prototype = { initialize: function() {} };"
      }'
